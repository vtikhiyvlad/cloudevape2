# Связка CloudVape ↔ Эвотор

CloudVape — **внутренний учёт** (остатки, инвентаризация, контроль продавцов).  
Эвотор — **основная касса с фискализацией**.

## Как заливать товары из Эвотора в CloudVape

### Способ 1 (рекомендуется): приложение «Обмен через Excel»

1. В ЛК Эвотор установите приложение **«Обмен через Excel»**
2. Мои приложения → Обмен через Excel → Управление товарами
3. Выберите магазин → **Выгрузить в Excel**
4. Скачайте файл
5. В CloudVape: Товары → магазин → загрузите Excel  
   (при необходимости приведите колонки к шаблону CloudVape)

Колонки CloudVape:
`Категория | Название | Характеристика 1 | Характеристика 2 | Цена | Остаток | Штрихкод`

### Способ 2: отчёт по остаткам CSV

Отчёты → Управленческие → Товарные остатки → на почту (CSV) → конвертация в наш шаблон.

### Что не дублируем

- Фискальные чеки — только Эвотор
- CloudVape фиксирует **внутренние** продажи/списания для контроля склада и инвентаризаций
- Идеальный процесс: номенклатура и штрихкоды совпадают в обеих системах
