# Деплой CloudVape на Render

Пошаговая инструкция специально под тебя.

---

## Что понадобится

1. Аккаунт на [render.com](https://render.com) (можно через GitHub)
2. Репозиторий на GitHub с этим проектом
3. Токен Telegram-бота от @BotFather

---

## Шаг 1. Залей проект на GitHub

1. Создай новый репозиторий на GitHub (например `CloudVape`)
2. Залей туда всю папку проекта
3. Важно: файл `.env` **нельзя** заливать в GitHub (там секреты)

---

## Шаг 2. Создай сервис на Render через Blueprint

1. Зайди в Render → **New** → **Blueprint**
2. Подключи свой GitHub-репозиторий
3. Render найдёт файл `render.yaml` и предложит создать:
   - Web Service (API)
   - Background Worker (бот)
   - PostgreSQL базу

4. Нажми **Apply**

---

## Шаг 3. Пропиши секретные переменные

После создания зайди в каждый сервис и укажи:

### Для cloudvape-api и cloudvape-bot:

| Переменная       | Значение                          |
|------------------|-----------------------------------|
| `BOT_TOKEN`      | Токен от @BotFather               |
| `OWNER_PASSWORD` | Пароль владельца (например `admin123`) |

`SECRET_KEY` и `DATABASE_URL` Render подставит сам.

---

## Шаг 4. Дождись деплоя

- API будет доступен по адресу вида:  
  `https://cloudvape-api.onrender.com`
- Документация:  
  `https://cloudvape-api.onrender.com/docs`
- Бот запустится автоматически как Worker

---

## Шаг 5. Первые действия

1. Открой `https://твой-адрес.onrender.com/docs`
2. Найди `/api/auth/login`
3. Войди:
   - username: `owner`
   - password: тот, что указал в `OWNER_PASSWORD`
4. Создай магазин через `/api/stores/`
5. Загрузи Excel с товарами
6. Напиши боту `/start` с аккаунта продавца

---

## Важные замечания по Render (бесплатный тариф)

- Сервисы засыпают после ~15 минут бездействия
- Первый запрос после сна может идти 30–50 секунд
- Для постоянного использования лучше взять платный тариф (от $7/мес)
- Бесплатная PostgreSQL тоже имеет ограничения

---

## Если что-то не запустилось

1. Смотри логи в Render (Logs)
2. Частые проблемы:
   - Не указан `BOT_TOKEN`
   - Бот не видит базу (проверь DATABASE_URL)
   - Ошибка порта (уже исправлено в Dockerfile)
