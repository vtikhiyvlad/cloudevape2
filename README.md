# CloudVape — CRM для вейп-шопов

Готовая система учёта продаж и остатков.

## Что уже работает

### Backend (API)
- Авторизация (владелец / админ / продавец)
- Мульти-магазин (данные полностью изолированы)
- Товары: категории → товары → варианты (крепость + вкус + цена + остаток)
- Загрузка товаров из Excel
- Атомарные продажи с защитой от пересорта
- История всех движений остатков
- Отчёт продаж за день

### Telegram-бот
- Регистрация продавца
- Процесс продажи: Категория → Товар → Вариант → Количество → Подтверждение
- Защита остатков (нельзя продать больше, чем есть)
- Просмотр остатков
- «Моя смена» (продажи и сумма за сегодня)

### Веб-интерфейс
- Базовый API готов
- Полноценный красивый веб-интерфейс будет дорабатываться следующим этапом

## Как запустить

### 1. Подготовка

```bash
cp .env.example .env
```

Открой файл `.env` и укажи:
- `BOT_TOKEN` — токен от @BotFather
- `OWNER_PASSWORD` — пароль владельца (по умолчанию admin123)
- `SECRET_KEY` — любая длинная случайная строка

### 2. Запуск через Docker

```bash
docker compose up -d --build
```

После запуска:
- API: http://localhost:8000
- Документация API: http://localhost:8000/docs
- Бот запускается автоматически
- Логин владельца: `owner` / пароль из `.env`

---

## Как пользоваться в первый раз

1. Зайди в API-документацию: http://localhost:8000/docs
2. Авторизуйся через `/api/auth/login` (логин `owner`)
3. Создай магазин через `/api/stores/`
4. Загрузи товары Excel через `/api/products/{store_id}/import-excel`
5. Добавь продавца и привяжи его к магазину (через API или базу)
6. Продавец пишет боту `/start` и может продавать
